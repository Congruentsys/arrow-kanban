# Code of conduct

arrow-kanban adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. It applies in every project space: issues, pull requests, discussions and
reviews, and wherever someone represents the project.

In short: be respectful and constructive, assume good faith, and critique code and ideas rather
than people. Harassment, personal attacks and discriminatory language are not acceptable.

## Reporting

Report conduct concerns **privately** to the maintainers:

- On the offending comment, issue or pull request, use GitHub's **⋯ → Report content** and choose
  to report it to the repository maintainers; or
- Open a private report from the repository's **Security** tab
  (<https://github.com/Congruentsys/arrow-kanban/security/advisories/new>) and start the title
  with `Code of conduct:`. Only the maintainers can see it.

Do not raise conduct concerns in a public issue. We aim to respond within 7 days. Reports are
handled confidentially, and the reporter's identity is not shared without their consent.

## Enforcement

The maintainers apply the Contributor Covenant 2.1
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban or permanent ban, according to the impact of the behaviour.
